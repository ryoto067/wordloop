# WordLoop 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 紙の単語帳で暗記する人向けに、周回タイマー・単語登録・忘却曲線に沿った復習・AI 文章化・朝夜の通知・連続日数を備えた PWA「WordLoop」を作る。

**Architecture:** `projects/wordloop/api` は Cloudflare Workers（Hono）＋ D1 ＋ Workers AI ＋ Cron Trigger（Web Push）。`projects/wordloop/web` は Vite + React の PWA で Vercel に置き、`/api/*` を Vercel rewrites で Workers に転送して同一オリジンに見せる。復習間隔・連続日数・通知判定は `api/src/domain/` の純粋関数に閉じ込めて単体テストする。

**Tech Stack:** TypeScript / Hono / Cloudflare Workers・D1・Workers AI・Cron / vitest + @cloudflare/vitest-pool-workers / Vite + React 19 + react-router / vite-plugin-pwa（injectManifest）/ idb-keyval / Playwright

**Spec:** `projects/wordloop/docs/superpowers/specs/2026-11-25-wordloop-design.md`（実装前に必ず通読。モック: `.superpowers/brainstorm/508-1795536245/content/flow-screens.html`, `visual-style.html` の C 案）

## Global Constraints

- 費用 0 円で動くこと（Workers Free / D1 Free / Workers AI 無料枠 / Vercel Hobby）。
- 単語の復習間隔の初期値 `[1, 3, 7, 14, 30]`、文章の初期値 `[3, 7, 14, 30, 60]`（日）。段階数は 1〜8 個で編集可。
- 間隔は **起点日（anchor）からの日数**。登録日が最初の起点、「忘れてた」を選んだ日が新しい起点。
- 文章化: 単語の最後の段階を「覚えてた」で通過 → `waiting_sentence`。10 語たまったら通知文に一文追加。5 語以上なら手動生成可。古い順に 10 語ずつ。AI 生成は 1 ユーザー 1 日 10 回まで（作り直し含む）。
- 文章の復習形式: 段階の日数が 30 未満なら穴埋め（cloze）、30 以上なら和訳 → 英文（recall）。最後の段階通過で `mastered`。
- 連続日数: 暗記セッション 1 回 or その日の復習を全部終える or 20 枚以上 → その日を達成。日付はユーザーのタイムゾーン（初期値 `Asia/Tokyo`）。
- 通知: 初期値 朝 `07:30`(morning)・夜 `21:00`(evening)。時刻は無制限に追加/変更/削除。夜・任意時刻は、その日の復習が終わっていれば送らない。
- 見た目: e スポーツ系。背景 `#0b0b0d`、パネル `#17171b`、ライム `#d7ff1e`、オレンジ `#ff5e1a`、斜めカット（clip-path）、太い斜体の数字。ドット絵・レトロ表現は禁止。色だけで意味を伝えない（文字・アイコン併記）。
- UI 文言は日本語。学習対象は英→日。
- 単語帳の書名・番号は扱わない。市販単語帳のデータは同梱しない。
- AI: `AI_PROVIDER=workers-ai`（既定, `@cf/openai/gpt-oss-120b`）/ `claude`（`ANTHROPIC_API_KEY`, `CLAUDE_MODEL` 既定 `claude-sonnet-5-5`）。
- 利用規模: オーナーと知人数人。Google OAuth は「テスト」状態で運用。
- 秘密情報（`GOOGLE_CLIENT_SECRET`, `VAPID_PRIVATE_KEY`, `ANTHROPIC_API_KEY`, `SESSION_SECRET`）は `wrangler secret` と `.dev.vars` のみ。`.dev.vars` と `.wrangler/` は `.gitignore` に追加。
- git のコミットは **オーナーが許可した場合のみ**（各タスク末の「チェックポイント」で可否を確認）。外部公開・デプロイ・アカウント作成はオーナー承認後。

## Review Focus

1. **タイムゾーンの日付境界** — 23:59 と 0:01（JST）に行った復習が別の日として扱われ、UTC で日付がずれないこと。→ Task 2・3 のテストに含める。
2. **オフライン中に行った復習の遅延送信** — 翌日に届いても `reviewedAt` の日付で採点・連続日数に反映され、同じ操作が二重送信されても 1 回分しか反映されないこと（`clientId` で冪等）。→ Task 6 のテスト。
3. **iPhone のホーム画面 PWA でのログイン** — ポップアップを使わずリダイレクトで完結し、ログイン後もホーム画面アプリ内に戻ること。→ Task 4（リダイレクト方式）＋ Task 14 の実機確認項目。
4. **期限切れの Push 購読** — 404/410 が返った購読は削除され、Cron 全体が止まらないこと。→ Task 8 のテスト。
5. **AI の出力が壊れている／単語が抜けている** — 目印が欠けた・JSON でない出力でもクラッシュせず、1 回だけ再試行し、それでもだめならエラー表示（回数は消費する）。→ Task 7 のテスト。

### Task 2: 日付と間隔計算（domain/dates.ts, domain/srs.ts）

**Files:** Create `api/src/domain/dates.ts`, `api/src/domain/srs.ts` / Test `api/test/srs.test.ts`, `api/test/dates.test.ts`

**Interfaces:**
- Produces: `localDate(at: Date, tz: string): string`（`Intl.DateTimeFormat` で YYYY-MM-DD）、`addDays(date: string, n: number): string`、`localHHMM(at: Date, tz: string): string`
- Produces: `type Card = { stage: number; anchorOn: string; nextReviewOn: string }`
- Produces: `startCard(today: string, intervals: number[]): Card` → `{ stage: 0, anchorOn: today, nextReviewOn: addDays(today, intervals[0]) }`
- Produces: `applyResult(card: Card, result: 'remembered'|'forgot', today: string, intervals: number[]): Card & { graduated: boolean }`
- Produces: `applyRoundTestForgot(card: Card, today: string): Card`

アルゴリズム（テストで固定）:
- `stage` は「次に行う復習の段階」の添字。段階数を超えていたら `intervals.length - 1` に丸めて扱う（間隔の設定変更対策）。
- remembered: `stage === last` なら `graduated: true`（カードはそのまま返す）。それ以外は `stage+1`、`next = anchor + intervals[stage+1]`。`next <= today` なら `today + 1`。
- forgot: `stage = max(stage-1, 0)`、`anchor = today`、`next = today + intervals[newStage]`。
- round test forgot: `stage = max(stage-1, 0)`、`anchor = today`、`next = today + 1`。

- [ ] **Step 1: 失敗するテスト**（すべて `[1,3,7,14,30]`）
  - `startCard('2026-11-01')` → next `2026-11-02`
  - 11/01 登録の単語を毎回期日どおりに覚えてた: 予定日が `11-02, 11-04, 11-08, 11-15, 12-01` の順。12-01 で `graduated: true`
  - stage1（3日目）で 11-04 に forgot → `{stage:0, anchorOn:'2026-11-04', nextReviewOn:'2026-11-05'}`、続けて 11-05 に remembered → next `2026-11-07`
  - stage3（14日目）で forgot → next = today+7
  - stage0 で forgot → stage0, next = today+1
  - 期日から 10 日遅れて remembered し、`anchor + 次の間隔` が過去 → next = today+1
  - stage=6 のカードに intervals `[1,3,7]` を渡す → stage2 として扱い remembered で graduated
  - `applyRoundTestForgot` stage2 → `{stage:1, anchorOn: today, nextReviewOn: today+1}`
  - dates: `localDate(new Date('2026-11-25T14:59:00Z'),'Asia/Tokyo')` = `2026-11-25`、`T15:01:00Z` = `2026-11-26`；`localHHMM(new Date('2026-11-24T22:30:00Z'),'Asia/Tokyo')` = `07:30`
