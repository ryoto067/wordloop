# WordLoop 設計書（2026-11-25）

> アプリ名「WordLoop（ワードループ）」は仮名（統括の提案）。オーナーが変更可。

## 1. 目的（なぜ作るか）

市販の**紙の単語帳**を周回して英単語を覚えている人が、エビングハウスの忘却曲線に沿った「思い出す作業」を毎日こなし、**単語暗記を習慣化**するための PWA。

アプリは「覚えたかどうかを判定する」ものではなく、**決まったタイミングで思い出す機会をつくる**もの。オーナー自身の学習法がベース：

1. 紙の単語帳を周回して単語を覚える
2. 覚えた単語を間隔をあけて繰り返し思い出す
3. 最初に覚えてから約 1 か月たった単語がたまったら、それらを使った**文章**にする
4. 以後は文章単位で、間隔をあけて覚え直す

## 2. ゴール / 非ゴール / アンチゴール

**ゴール**
- 紙で周回した時間を測り、その回に覚えた単語を素早く記録できる
- 単語カードで復習し、自己判定（覚えてた / 忘れてた）で間隔が自動で伸び縮みする
- たまった単語から AI が文章を作り、その文章も間隔反復で復習できる
- 朝・夜（ほか任意の時刻）にプッシュ通知が届き、連続日数で続ける動機が生まれる
- 他の人も使える（Google ログイン、データはクラウド保存）

**非ゴール（今回はやらない）**
- 単語帳（書名・番号）との紐づけ。単語だけを登録する
- 市販単語帳の単語データの同梱（著作権上不可）
- AI による訳の自動入力（自分で打つこと自体が暗記になるため外した）
- 自分で単語を集める人向けの機能（将来候補）
- XP・レベル・デイリークエスト・ランキング・フレンド
- ネイティブアプリ化

**アンチゴール（動いても失敗とみなす状態）**
- 記録や復習の操作が重く、続けるのが面倒になる
- 通知がうるさくて通知ごとオフにされる
- ネオン・装飾が強すぎて単語が読みにくい
- 誤タップ・誤スワイプで復習間隔が勝手に進む

## 3. 制約

- 公開: GitHub → Vercel（フロント）
- バックエンド: Cloudflare（Workers + D1 + Cron Triggers + Workers AI）
- 費用: 初期 0 円。無料枠内で運用し、超えそうなら検討
- iPhone の通知は **ホーム画面に追加した PWA でのみ**届く（iOS 16.4 以降）→ 初回に追加手順の案内が必須
- 言語: 画面は日本語。学習対象は英単語（英→日）

## 4. 検討したアプローチ

| 項目 | 候補 | 採用 | 理由 |
|---|---|---|---|
| 画面 | **Vite + React** / Next.js | Vite + React（オーナー選択） | 処理は全部 Cloudflare 側なので、Next.js のサーバー機能が不要。PWA 化も vite-plugin-pwa で簡単 |
| ログイン | **Google** / ログインなし＋引き継ぎコード / メールリンク | Google（オーナー選択） | ボタン 1 つ、機種変更でも引き継げる、0 円 |

| 全部 Cloudflare Pages | — | 不採用 | オーナーが Vercel を指定 |

## 5. 決まったこと（オーナー決定）

### 5.1 画面の流れと見た目
- **見た目: 「e スポーツ系」**（ブレスト時のモック C）。黒ベース（#0b0b0d）、斜めカットのパネル、太い斜体の数字、差し色は蛍光ライム（#d7ff1e）とオレンジ（#ff5e1a）。ネオンは差し色程度。レトロ・ドット絵は不可。
- モック: `.superpowers/brainstorm/508-1795536245/content/visual-style.html`（C 案）、`flow-screens.html`（主要 4 画面、オーナー OK 済み）
- **ホーム**: 連続日数（大きな斜体数字＋🔥）、今日の単語の復習数、今日の文章の復習数、「▶ 暗記スタート」ボタン。下部ナビ: ホーム / 復習 / 文章 / 記録

### 5.2 暗記セッション（単語の登録・周回テスト）
- 「暗記スタート」を押すと、まず **何周目か** を選ぶ（1 周目 / 2 周目 / 3 周目 / 4 周目〜）。
- **1 周目**
  1. **タイマーだけの画面**（紙の単語帳を周回している時間を測る）。**周回数（ROUND 01 など）を表示**。STOP で終了。
  2. STOP 後、**英単語 → 日本語訳 → 英単語 → 日本語訳…と交互に入力**。Enter で次の欄へ。入力済みは下に一覧表示し、タップで修正。
  3. 「保存して完了」で、入力した単語が **1 つの「セット」**（例:「11/20 セット（25 語）」）として登録される。登録日が復習の起点。
- **2 周目以降**
  1. **どのセットの周回か**を選ぶ（初期選択は直近のセット）。
  2. タイマー画面（「SET 11/20 ・ ROUND 02」のように表示）→ STOP。
  3. **単語入力はなし**。代わりにそのセットの単語を**単語カードでテスト**（覚えてた / 忘れてた を自己判定）。
  4. 結果画面（覚えてた 21 / 忘れてた 4）。**「忘れてた」単語だけ翌日の復習に出す**。「覚えてた」単語は今の予定のまま。
- 単語帳との紐づけはしない（単語と訳だけ）。

### 5.3 単語の復習（単語カード）
- 英単語を表示 → タップでめくって訳を表示 → **本人が「覚えてた / 忘れてた」を選ぶ**。
- 間隔: **1 → 3 → 7 → 14 → 30 日**（初期値。本人が変更可）。**起点（最初に覚えた日、または最後に「忘れてた」を選んだ日）からの日数**で数える。例: 11/1 に登録 → 11/2・11/4・11/8・11/15・12/1 に復習（約 1 か月で文章へ）。
- 「覚えてた」→ 次の段階へ。「忘れてた」→ **間隔を 1 段階戻し、その日を新しい起点にする**（例: 3 日目で忘れた → 翌日にもう一度 → 覚えていたらその 2 日後に 3 日目の復習）。
- 誤操作対策: 大きなボタン＋スワイプ（画面幅の半分以上で確定）、「1 つ戻す」ボタン。

### 5.4 文章づくり
- **AI が、たまった単語を整理して文章（英文＋和訳）を作る**。作り直し・手直し可。

### 5.5 文章の復習
- 単語より**広い間隔**を初期値にし、本人が変更可。
- 形式: **穴埋めが基本**（覚えた単語の部分を空欄に → タップで答え）。**復習が進んだら「和訳だけ表示 → 英文を思い出す」形式に切り替え**。

### 5.6 ゲームらしさ
- **見た目・操作感と連続日数だけ**。XP・レベル・クエストは入れない。

### 5.7 通知
- **朝 1 回・夜 1 回**を初期設定。**時刻は自由に追加・変更・削除できる（回数無制限）**。

### 5.8 AI
- Cloudflare Workers AI で開始。最初のモデル候補は `@cf/openai/gpt-oss-120b`。
- 環境変数で Claude API（Anthropic）に切り替えられる作りにする。

### 5.9 ログイン・データ
- Google ログイン。データは Cloudflare D1 に保存し、端末を替えても引き継げる。

### 5.10 利用規模
- **まずはオーナーと知り合い数人**。Google OAuth は「テスト」状態で運用し、利用者のアドレスを登録する。
- あとから一般公開に移れる作りにしておく（AI の回数制限は最初から入れる）。

## 6. 統括の判断（オーナーが確認・変更できる提案）

| 項目 | 判断 | 理由 |
|---|---|---|
| 文章化のタイミング | **30 日目の復習を「覚えてた」で通過した単語**を「文章待ち」に移し、**10 語たまったら**ホームと通知でお知らせ。ボタンで AI 生成 | 「最初に覚えてから約 1 か月」に合わせた |
| 文章待ちになった単語 | 単語カードの復習からは外れ、以後は文章の中で復習 | 二重の復習を避ける |
| 文章の生成単位 | 10 語で 2〜4 文程度の短いストーリー。全単語を必ず使う。和訳つき | 覚えやすい長さ |
| 文章の復習間隔 | **3 → 7 → 14 → 30 → 60 日**（初期値・変更可）。忘れた → 1 段階戻す（単語と同じ） | 「もう少し広く」の要望 |
| 形式の切り替え | 30 日段階以降は「和訳 → 英文を思い出す」 | 段階が進むほど難しく |
| 穴埋めの判定 | 文章全体で「覚えてた / 忘れてた」を 1 回だけ選ぶ | 操作を軽く |
| 文章の最終段階後 | 60 日を通過したら「マスター」として復習終了（記録には残る） | 終わりがないと負担が増え続ける |
| 単語の 30 日段階で忘れた場合 | 14 日に戻す（ルールどおり） | — |
| 1 日目で忘れた場合 | 翌日にもう一度（1 日段階のまま） | これ以上戻せないため |
| 復習の期限 | 予定日以降はずっと「今日の復習」に残る（遅れても消えない）。次の予定は「起点 + 次の段階の日数」。それが既に過ぎていれば、翌日に出す | 起点基準（オーナー決定）を守りつつ、同じ日に連続で出さない |
| 周回数の表示 | 1 周目はセットごとに ROUND 01、2 周目以降はユーザーが選んだ周回数を表示 | — |
| 同じ単語の重複入力 | 1 周目の入力で、既に別セットにある単語は「登録済み」と表示してスキップ（進み具合はそのまま）。今回のセットにも含めたい場合は「このセットにも入れる」を押すと、同じカードをこのセットに紐づける（カードは 1 枚のまま） | 2 周目テストの対象にはしたいが、進み具合は壊さない |
| 間隔の設定変更 | 既に復習中の単語・文章は、次回の予定から新しい間隔で計算。「文章待ちに入る」「マスター」は日数ではなく「最後の段階を通過したら」で判定。段階は 1〜8 個の範囲で編集可 | 段階の追加・削除に耐える |
| 連続日数 | その日に **暗記セッション（何周目でも）を 1 回行う** か **その日の復習を全部（遅れ分含む）または 20 枚以上終える** と 1 日カウント。どちらもしない日は途切れる。オフライン時の復習は実際に行った日で数える。日付の切り替えはユーザーのタイムゾーン（初期値 Asia/Tokyo）の 0:00 | たまった復習で連続日数が不可能にならないように |
| 「記録」タブ | 単語一覧（検索・編集・削除）、セット一覧（周回履歴・時間・テスト結果）、連続日数カレンダー、マスターした文章 | — |
| 単語の編集・削除 | いつでも可。文章に使われている単語を削除するときは警告し、文章はそのまま残す | — |
| 文章待ちが 10 語超 | 古い順に 10 語ずつ 1 文。まとめて何文でも作れる。10 語未満でも 5 語以上なら手動で作成可。AI 生成は 1 人 1 日 10 回まで（作り直し含む） | 無料枠を守る |
| 単語の形の変化 | AI には単語を `[[abandoned|abandon]]` の目印つきで出力させ、穴埋めは変化した形を空欄にする。手直しで目印が消えた単語があれば保存前に警告（保存は可、その単語は穴埋め対象外） | abandon → abandoned などに対応 |
| 「1 つ戻す」 | 直前の 1 枚だけ取り消せる | 誤操作対策として十分 |
| 単語の保存 | オフラインでも端末に一時保存し、オンラインで送信 | 電車内で使える |
| 通知の初期時刻 | 朝 7:30・夜 21:00 | 通学・就寝前 |
| 通知の文面 | 朝:「今日の復習 単語 18・文章 2。🔥12 日連続」/ 夜（未完了時）:「まだ復習が残っています。🔥12 日を途切れさせないで」/ 夜（完了時）は送らない or 軽い一言 | 完了済みの人にはしつこくしない |
| 文章化のお知らせ | 10 語たまったら次の通知に一文を足す（単独の通知は増やさない） | 通知を増やしすぎない |
| オフライン | 画面はオフラインでも開ける（Service Worker）。復習結果はオフライン時は端末に一時保存し、オンラインで送信 | 電車内で使える |
| 初回案内 | iPhone で Safari から開いた場合「共有 → ホーム画面に追加」の図解。追加後に通知の許可をお願いする | iOS の制約 |
| 法的ページ | プライバシーポリシー・利用規約ページを用意（Google ログイン・他人が使うため） | 必須 |
| API の置き場所 | Vercel の rewrites で `/api/*` を Cloudflare Workers に転送し、同じドメインに見せる | iPhone Safari の第三者 Cookie 制限を避け、ログイン状態を安定させる |
| Google ログイン方式 | リダイレクト方式（ポップアップは使わない）。Worker が ID トークンを検証し、HttpOnly Cookie のセッションを発行 | ホーム画面 PWA ではポップアップが不安定 |
| 表示設定 | 文字サイズ変更、色覚に配慮した配色（ライム/オレンジだけに意味を持たせない、アイコン・文字も併記） | 読みやすさ |
| フォルダ | `projects/wordloop/`（`web/` = Vite、`api/` = Workers） | ハブの構成に合わせる |

## 7. 技術構成

```
[スマホ PWA (Vite + React)]  ── https://<app>.vercel.app
        │  /api/*  （Vercel rewrites）
        ▼
[Cloudflare Workers (Hono)] ── D1（データ）
        │                   ├─ Workers AI（gpt-oss-120b）※Claude API に切替可
        │                   └─ Cron Trigger（毎分）→ Web Push（VAPID）
```

### データ（D1）の主なテーブル（案）
- `users`（id, google_sub, email, name, timezone, word_intervals, sentence_intervals, created_at）
- `sessions`（ログインセッション）
- `word_sets`（id, user_id, name 例「11/20 セット」, created_at）
- `set_words`（set_id, word_id）※1 枚のカードが複数セットに属せる
- `study_rounds`（id, user_id, set_id, round_no, started_at, duration_sec）
- `round_tests`（round_id, word_id, result: remembered / forgot）※2 周目以降のテスト結果
- `words`（id, user_id, english（ユーザー内で一意）, japanese, stage, anchor_on（起点日）, next_review_on, status: reviewing / waiting_sentence / in_sentence, created_at）
- `word_reviews`（id, word_id, reviewed_at, result: remembered / forgot）
- `sentences`（id, user_id, english_text, japanese_text, stage, next_review_on, status: reviewing / mastered）
- `sentence_words`（sentence_id, word_id, 文中の位置）
- `sentence_reviews`（id, sentence_id, reviewed_at, mode: cloze / recall, result）
- `push_subscriptions`（id, user_id, endpoint, keys, created_at）
- `notify_times`（id, user_id, time "07:30", kind: morning / evening / custom）
- `daily_activity`（user_id, date, did_round, finished_reviews）→ 連続日数の計算に使う

### 通知
- Web Push（VAPID 鍵）。Cron が毎分起動し、各ユーザーのタイムゾーンで「今の時刻 = 通知時刻」の人に送る。
- 期限切れの購読（410 応答）は削除する。

## 8. ビルダーに任せること
- 画面の細部（余白・アニメーション・効果音の有無）。モックの雰囲気を守ること
- Workers のライブラリ選定（Hono 推奨）、マイグレーションの書き方
- テストの粒度（間隔計算・連続日数・通知時刻判定は単体テスト必須）
- Workers AI のプロンプト文面（全単語を使う・自然な英文・高校〜大学受験レベル）
- アイコン・ロゴ
